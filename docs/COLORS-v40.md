# v40 — 配色スウォッチライブラリ

## 変更
- 編集画面の共通 `.design-choice` 背景が単色色見本を白く上書きしていた問題を修正。選択時も元の色を保ち、枠とチェックで選択状態を示す。
- カラータブの先頭に写真なしの配色ライブラリを追加。やさしい／自然／クラシック／ポップ各4組、計16組を横スクロールで選択する。
- 見本に表紙色、文字の読み心地、3色の帯を表示。タップで表紙・文字と飾り・背表紙の文字を一括適用する。
- タイトル、写真、書体、枠、レイアウトは配色変更によって変更しない。
- 各色は引き続き個別調整可能。配色選択は1回の履歴操作とし、もどす／やりなおす・選択表示を同期。
- 保存には既存の customBg/customAccent/customInk を利用。DB名、バージョン、色配列順は変更しない。
- デモ表示v40、サービスワーカーキャッシュdemo-v17。

## 検証
Chromiumの390×844で実操作。320/390/768px・高さ568pxで横はみ出しなし。
- 単色色見本のcomputed backgroundが各色の実値に一致し、選択状態でも保持。
- 16配色すべての表紙色と文字2色のコントラスト比は4.5以上（装飾・写真・質感を重ねる前の値）。
- カテゴリー絞り込み、ライブプレビュー3色、個別変更、単色へ戻す、undo/redo。
- 新規作成して保存・再読込後も3色を保持。
- 既存図鑑で配色変更しても写真・タイトル・書体・枠を保持。
- JavaScript構文、diff空白検査、ブラウザコンソール例外なし。

結果は qa/palette-v40.json。iPhone/Safari実機は未確認。

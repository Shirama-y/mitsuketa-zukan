# v42 — 操作構造の整理とユニバーサルデザインへの改善

## 操作構造の監査

| 対象 | 変更前の問題 | 今回の整理 |
| --- | --- | --- |
| ホーム・図鑑 | `/collections` が本棚を再描画する別名として残る | 旧リンクは履歴を増やさず `#/` に正規化 |
| 検索 | 同じカテゴリの文字ボタンと写真ボタン、日本語の単語推定が重複 | 実際に保存された自由タグを一つの選択欄で絞り込む |
| 検索結果 | 図鑑・記録の検索と書かれているが記録のみ検索 | 図鑑名・副題の結果と記録を分けて表示。結果より上の大型バナーを撤去 |
| 検索の役割 | 自分の記録検索で公開図書館のナビが選択状態 | 本棚側の検索として表示。公開作品と個人記録を区別 |
| 本棚の編集 | 表紙編集とページ編集が常時別ボタン。表紙編集の名前が「図鑑を編集」 | 「本をひらく」「図鑑を編集」の2操作。編集メニューで表紙／中のページを明示 |
| 表紙画面 | 5つの操作が並び、削除も読書と同列 | 同じ編集メニューへ統一。お気に入りと削除は管理の開閉欄へ |
| 記録一覧 | デザインボタンと中のページ設定が重複 | 共通編集メニューの一つに統合 |
| 書斎 | 本棚と公開図書館へのボタンが下部ナビと重複 | 共同編集・ふりかえり、表示と操作、データ、使い方の4群に整理 |
| データ | 保存状態・バックアップ・復元が別々 | `/storage` の「バックアップ・復元」に統合 |
| 新規記録 | 8項目を最初から表示 | 写真・名前・観察を基本とし、日付・場所・タグ・別名・物語は任意詳細へ |
| ホームの下部 | 記録・ふりかえり・検索へ同様の誘導が反復 | 最近の記録だけを残し、ふりかえりは書斎、ヒントは検索の開閉欄へ |

表紙スタジオ内の「ページ」は装丁と一緒に設定するためのプレビュー付きツールとして維持。独立したページスタジオは読書から配置を調整する用途。記録一覧とページめくり表示も、検索と読書の異なる用途なので残しています。公開用スナップショットと共同編集下書きは共有範囲が異なるため統合していません。

## デザイン・アクセシビリティ

- 共通操作はネイビー／白と統一線画アイコン。ユーザー自身の表紙の配色・写真・装飾は維持し、性別で選択を制限しない。
- 設定行は行全体を押せるボタン。主要ボタン44px以上、選択は色に加えて下線・チェック・aria状態で示す。
- 文字拡大、動きを減らす設定を端末内に保存。OSのreduced-motion設定も引き続き尊重。
- ページ移動後は見出しへフォーカス。既存のダイアログのフォーカストラップと未保存確認を維持。
- ナビの英語補助ラベルと日英の基本ガイド。記録名の新規・編集入力上限は100文字へ統一。
- タグ分類を日本語のキーワード推定に依存させない。入力内容を自動翻訳しない。

人種・性別などの属性による利用制限は追加していません。今回の変更は全言語対応やアクセシビリティ認証を意味しません。全画面の翻訳・言語切替、RTL全画面対応、VoiceOver/TalkBack実機検証は未実装・未確認です。

# v37 — 新規図鑑から装丁、配色テーマ、立体の本棚

## 作成体験
「新しい図鑑」と「記録する → 新しい図鑑をつくって記録」は、既存図鑑と同じ8ツールの装丁室へ進みます。上部のプレビューを見ながら表紙の画像・色・文字・質感・枠・ステッカー・ページレイアウトを整え、最後の「つくる」で保存します。
空のタイトルは入力を促します。作成前に戻っても空の図鑑は作られません。新規図鑑と装丁設定を一回のIndexedDBトランザクションで保存し、失敗時は下書きを残して再試行できます。記録から来た場合は作成後に最初の写真を選べます。

## デザインテーマ
テーマの写真・イラストのサムネイルを廃止し、表紙・文字・差し色の配色見本に変更しました。画像付き表紙のテンプレートと自分の写真を使う機能は維持します。

## 本棚の立体モデル
表紙・裏表紙・背・小口・天・地の6面を同じ寸法・座標系の立体として構成。全体だけを回転・移動し、各面が離れないようにしました。旧表紙に付いた疑似ページ端、背表紙だけの上下余白、各面の丸みの差を棚上で除去し、継ぎ目を揃えています。奥行きの透視投影で回転中の前後関係を表現します。画像素材は既存の表紙・紙・布の実画像を継続利用します。

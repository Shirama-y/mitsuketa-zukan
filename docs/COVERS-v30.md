# 写真表紙と読み心地の改善 v30

- 新規作成・テーマ編集で写真の追加、交換、上下位置、削除。JPEGへ縮小し端末内に保存。画像は最大1000px、入力30MBまで。
- 写真とタイトルを分けた装丁。布・紙の実画像、綴じ目・ページの厚み、背表紙を調整。長いタイトルは本棚下に全文表示。
- 手書き Klee One、丸ゴシック Zen Maru Gothic、楷書 Kaisei Opti をライセンス付き同梱。既存の明朝・ゴシックと合わせ5種類。Google Fonts公式TTFをWOFF2へ変換し字形・レイアウトテーブルを保持。
- 中のページで3レイアウト、写真の3形状、5書体、文字サイズ、余白、日付・場所・メモの表示を設定。実際の記録でプレビュー。
- 写真付きカテゴリー6項目。鳥・空・小さなたからものの生成写真素材を追加し、ヒントを6件へ拡充。
- 写真・設定をバックアップに含む。不正な表紙画像は復元前に検証。既存DB名・バージョン・色柄枠の配列順を維持。

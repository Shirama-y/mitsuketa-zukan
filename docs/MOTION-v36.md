# v36 — スクロールに連動する本棚と編集の修正

## 本棚
- 本を入れ替えて幅を切り替える表示から、同じDOMを保持する3D表紙・背表紙モデルへ変更。
- ネイティブ横スクロール量に合わせて回転角、横位置、持ち上がりを毎フレーム更新。中央で表紙が開き、離れると背表紙に戻る。
- 投影幅から各冊の位置を計算し、22〜24pxの間隔を保持。最初と最後の本も中央に配置。
- タッチの慣性、マウスドラッグ、矢印・Home/End、選択位置の復元に対応。動きを減らす設定ではボタン移動を即時化。
- 左右の側板を持たないウォルナット棚の実画像を新規作成。上下の棚板と背板のみを横方向へ連動移動。

## 編集の修正
- 全面写真・イラストでも基本の枠と文字の左右位置が反映される。基本枠を選ぶと金の飾り枠は解除され、undoで復元できる。
- 中のページのレイアウト選択表示をundo/redoと同期。
- 一連の文字入力・スライダー操作を一つの履歴としてまとめ、最大48段階を保持。
- 表紙プレビューは既存の画像ノードを維持して更新し、入力ごとの画像再挿入を解消。
- 写真読み込み中は保存と履歴操作をロック。保存の二重実行を防ぎ、失敗時は編集内容を保持して再試行を案内。
- 背景の暗さの未設定値を0に揃え、表示とスライダー値の不一致を修正。
- ナビ・写真・編集・共有・削除・お気に入り・履歴・編集タブを同じ線幅と端形状のSVG操作アイコンへ統一。表紙用イラストは実画像のまま維持。

枠・文字位置・入力単位のundo/redo・ページ選択同期・保存と再読込を確認。写真アップロード、加工、写真とテンプレート切替、undo/redo、320×568の編集画面を回帰確認。

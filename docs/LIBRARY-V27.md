# わたしの図鑑 v27（2026-09-28）

ユーザーの依頼により、図書館の写真・アイボリー・ゴールドのUI、本棚型Myライブラリ、表紙作成、5項目ナビへ刷新しました。

## 実装
- app.js、assets/design-tokens.css、assets/library-ui.css に分離。
- 日本語フォントを同梱（Zen Kaku Gothic New / Shippori Mincho、ライセンス同梱）。
- スマホの余白、文字組、ボタンサイズ、長いタイトルを調整。
- 写真の読み込み失敗を案内。編集途中の破棄確認、削除確認を実装。
- 名前・タグ・場所・メモを複数語で検索。全半角・かなを正規化、検索条件を保持。
- バックアップ検証と一括復元、旧Blob写真の書出し対応。
- IndexedDB名 ishi-no-wakusei / version 4を維持。既存の色・柄・枠の番号と欠番を維持。
- GitHub版ではデモ記録を投入しない。デモ版とは保存先を分離。

# v41 — スマートフォンのヘッダーと下部ナビ

ヘッダーと下部ナビの角丸をなくし、画面端へまっすぐつながる形に変更しました。カードや入力欄の角丸は維持しています。

- 画面幅と高さに応じたヘッダーの高さ・余白・タイトル文字サイズ。
- ノッチ・ホームバー・横向きの左右セーフエリアを考慮した配置。
- ナビの実測高を本文の下余白へ反映。パディングの変化も拾うborder-boxのResizeObserverを使用。
- VisualViewportの高さ変更に合わせてナビ位置を更新。ピンチ拡大中はブラウザの拡大操作を妨げない。
- 横向きの低い画面ではナビのアイコンとラベルを横並びにして表示領域を確保。
- 編集画面と読書画面では従来どおりメインヘッダー・ナビを非表示。

## 確認
Chromiumで320×568、375×667、390×844、430×932、844×390、768×1024。本棚・発見・公開図書館・書斎で角丸ゼロ、左右はみ出しなし、ナビラベルの収まり、本文下余白、スクロール時のヘッダー固定を確認。
ホームバー分の余白増加とキーボードによるVisualViewport縮小・復元はシミュレーションで確認。iPhone/Safari実機では未確認。
既存データ・保存形式は変更していません。デモv41、キャッシュdemo-v18。

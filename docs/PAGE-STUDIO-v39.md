# v39 — 横スワイプのページ編集と紙のめくり

「中のページをつくる」を全画面の編集スタジオへ変更しました。プレビューと保存ボタンは固定し、組み方／配置／文字組／書体／紙・余白／表示の6ツールを横スワイプできます。

配置は図解アイコンで選びます。写真は上・下・左・右・おまかせ、文字は左・中央・右揃え。雑誌・図鑑・物語・アルバム、縦横書き、段組、見出し・説明文の書体、紙色、余白、日付等の表示をプレビューへ反映します。既存の一覧形式の設定も保持しています。

ページめくりは、ページ画像の単純な平面回転から8つの連続する帯で構成した紙の変形へ変更。端に向かってしなりを増やし、紙の裏面と厚み、次ページへ落ちる影を動かします。前後のめくりと動きを減らす設定に対応。アニメーション終了時と画面変更時に描画用の層を除去します。

## 確認
- 6ツールのタッチスワイプ・固定プレビュー・アイコン選択・保存後の再読込。
- 320/390/768px、高さ568pxでもプレビュー・保存・ツールを操作可能。
- 上下左右の配置で長文が次ページへ続き、原文と一致。見出しと本文の重なりなし。
- 進む・戻るの紙の変形、8面の裏側、影の消去、reduced motion。
- 配置・文字揃えの共有API保持、不正な配置値の拒否、バックアップ復元。

# v35 — 横に選ぶ本棚と、物語の装丁室

## 本棚

実際に横スクロールする本棚へ変更しました。中央の一冊だけ表紙を開き、その他は背表紙で表示します。指を離すと近い本に収まり、タップ、マウスドラッグ、左右キー、先頭・最後の移動に対応します。選択した本を端末内に保持します。

本ごとの幅を確保したうえで22〜24pxの間隔を取り、3Dの紙の厚みも隣の本へ重ならないようにしています。スクロールの両端でも中央配置を保ちます。既存の図鑑や写真、並び順は変更しません。

## 装丁室

ネイビーと金、紙の色を基調に、プレビューと保存ボタンを固定。テンプレート／タイトル／カラー／写真・背景／フレーム／飾り／テーマ／ページの8つを横スクロールで切り替えます。候補の一覧も横に選べます。

- 新規の絵柄3種：ほしぞら探検記、ひみつの森、海の底のふしぎ。
- 写真を飾る／全面に広げる／丸い窓の3構成。
- 独立した透明の金色装飾枠。自分の写真とも組み合わせ可能。
- 写真とテンプレートの絵を切替。元の写真は保持します。
- タイトルの上・中央・下配置、ラベル背景、文字間隔。
- 背景の暗さ、既存の写真加工・位置・拡大・フォント・文字のフチ。
- 既存の実画像アイコンをステッカーとして配置。左右・中央とサイズを調整。
- 編集操作を24段階まで戻す／やり直す。

テンプレートはタイトルを上書きしません。生成イラストに文字は焼き込まず、入力したタイトルを別のUI層で表示します。アプリ実行時の画像生成やAPI課金はありません。素材生成のプロンプトは cover-prompts-v35.json に記録しています。

## 保存と確認

個人のIndexedDB、バックアップの書出し・復元、共同編集の共有保存に新しい表紙の設定を反映しました。既存DBの版と旧データは維持。共有APIは許可された値と数値範囲を検証し、外部画像URLを受け付けません。

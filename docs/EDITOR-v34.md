# v34 — 本棚と、見ながらつくる編集画面

ホームと図鑑一覧の重複を解消し、個人の図鑑を「本棚」に統一しました。下部ナビは本棚／記録する／公開図書館／書斎の4項目です。旧 collections URL は同じ本棚を表示し、お気に入り・最近のフィルターを維持します。

本棚の「図鑑を編集」から、保存済み図鑑のタイトル、フォント、文字のフチ、色、写真、装丁、中のページを変更できます。上部にプレビューと保存ボタンを常時表示し、6種類の編集ツールを横スワイプ・タブ・キーボードで切り替えます。各ツール内も横に選べるトレイと縦スクロールを使います。ページの編集時には、実際の最初の記録を上部に縮小表示します。未保存変更の確認、写真取り込み中の保存禁止を維持しています。

表紙の色はプリセットと任意のカラーに対応。既存の実画像素材を色になじませ、背・紙の厚み・遠近感を加えました。長いタイトルとサブタイトルは編集プレビュー内に収まるよう調整します。

「記録する」には常に新規図鑑の作成を表示。作成後の「写真を選んで記録する」から最初の記録に進みます。写真をまだ選ばなくても作成した図鑑は残ります。公開は従来どおり公開図書館で明示的に操作します。

ページめくりは、次のページの上で一枚が綴じ目を軸に回転します。逆方向、連打の抑制、スワイプ、キーボード、動きを減らす設定に対応。個人の図鑑と共有・公開図鑑で共通です。

## 確認

- Chromium: 320 / 390 / 768 px の編集画面、文字・ボタンの位置、画面の横はみ出し。
- 固定プレビュー、タッチイベントによる横スワイプ、24文字タイトル＋48文字サブタイトル＋表紙写真の収まり。
- 既存図鑑のタイトル・色・写真・加工・ページ設定を変更し、保存と再読み込みで保持。
- 「記録する」→新規図鑑→写真選択→記録保存。
- 前後のページ回転と reduced-motion 時の即時切替。
- 既存の共有API権限・競合・公開版分離の検証も成功。バックエンドとDB構造は変更なし。

結果: qa/experience-v34.json、qa/touch-v34.json。iPhone / Safari 実機での確認は未実施です。GitHub版は従来のDB名とデータを維持し、デモ用サンプルを投入しません。GitHub Pagesで共同編集APIは動作せず、共有機能には既存のcloud/バックエンドが必要です。

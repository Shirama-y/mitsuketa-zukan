# v29：自分の一冊をつくる

- 本棚は保存済み図鑑の背表紙を並べ、選択中の一冊だけ表紙を表示する。
- 選んだ本が中央に来る。背表紙のタップ、前後ボタン、左右キーで選択できる。
- 選択を端末内に保存。本が増えても全冊にアクセスできる。表示のための架空の本は追加しない。
- 表紙を押して中を開く。表紙編集と中のページ編集は同じ本棚から進める。
- 中のページは「図鑑リスト」「写真アルバム」「観察日記」の3種類。
- 日付・場所・日記の観察とストーリーの表示を切り替える。元のデータは維持。
- 実際の記録で先頭2件をプレビュー。空の図鑑は見本表示のみで、記録は作らない。
- 作成時にも中のページを選べる。既存の表紙・質感・文字・レイアウト密度の設定を維持。
- pageLayout / pageDate / pagePlace / pageNotes を図鑑の追加属性として保存し、バックアップにも含める。DB版・保存名・採番は変更しない。

# みつけた図鑑

子どもが自分で図鑑をつくり、身のまわりで見つけたものを写真と言葉で記録していくアプリ。
石でも、車でも、花でも、レゴでも、ペットボトルのキャップでもよい。図鑑のタイトルは
子ども自身が決める。

正しい名前を調べる科学図鑑ではなく、**よく見て気づく力を育てる「観察のトレーニング」**
として作っている。DODOLABO の活動で、子どもが実際に触れることを想定している。

設計の判断と、その理由は [CLAUDE.md](CLAUDE.md) にまとめてある。
**コードを触る前に、まずそこを読んでほしい。**

## 中身

```
index.html   アプリ本体。これ1枚で動く。ビルドもサーバーも不要
CLAUDE.md    設計の判断と理由。Claude Code が自動で読み込む
tools/       手元の作業道具（アプリの動作には不要）
```

## 動かす

`index.html` をブラウザで直接開いても、ほとんどの画面は見られる。ただし
**Chrome はローカルファイルから IndexedDB を使わせない**ので、記録の保存を試すときは
簡易サーバー越しに開くこと。

```sh
cd "<このフォルダ>"
python3 -m http.server 8777
# → http://localhost:8777/ を開く
```

## 直すときの約束

守らないと、すでに子どもが作った図鑑が壊れる。

- **`COVERS` / `PATTERNS` / `FRAMES` を並べ替えない。** 配列の順番が、保存されている
  `color` / `theme` / `frame` の番号そのもの。足すときは必ず末尾に
- **番号を詰めない。** 記録を消しても `nextNo` は戻さない。欠番は欠番のまま残す
- **IndexedDB の移行処理を作り直さない。** 既存ユーザーのデータを消さないことが最優先
- **実行時に AI や外部 API を呼ばない。** 運用コストをゼロに保つための制約
- **観察欄と想像欄を統合しない。** 事実と想像を分けて書く練習が、このアプリの核

## 試す

保存まわりを触ったら、実ブラウザでの試験を通すこと。ヘッドレスの仮想時間では
IndexedDB のコールバックが発火しないので、Chrome を DevTools プロトコルで
直接動かしている。

```sh
# 1) アプリを配信しておく
python3 -m http.server 8777

# 2) 別のターミナルで Chrome を起動
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --remote-debugging-port=9333 \
  --user-data-dir=/tmp/zukan-profile --no-first-run about:blank &

# 3) 試験（作成・追加・削除・欠番・写真・5回リロード の8項目）
node tools/reload-test.mjs 9333 run /path/to/なにかの写真.jpg
```

`node tools/reload-test.mjs 9333 verify` は、何も書かずに残っている中身だけを読む。
ブラウザを終了して起動し直したあとの確認に使う。

## 公開する

claude.ai のアーティファクトとして公開している。アーティファクトは
`<html>` `<head>` `<body>` を自前で付けるので、そのぶんを外したものを渡す。

```sh
python3 tools/build-artifact.py index.html artifact.html
```

できた `artifact.html` を、既存のアーティファクトと同じ URL へ上書き公開する。
